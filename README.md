# Awan Prediction AI 2.0

Signal-only research dashboard.

## Included
- LIVE Forex mode with public Deriv market-data WebSocket
- USD/JPY, EUR/USD, GBP/USD, AUD/USD, USD/CAD
- TradingView-style candlestick chart using Lightweight Charts
- 1m, 5m, 15m chart timeframes
- EMA 9/21
- +1 and +2 directional signals
- LIVE and OTC modes kept separate

## Important
The OTC selector intentionally does not substitute ordinary LIVE Forex prices. To make OTC candles match a specific broker such as Quotex, an authorized/access-permitted OTC feed for that broker is required.

The displayed confidence is a model estimate, not verified accuracy and not a guarantee. The project does not place trades automatically.
